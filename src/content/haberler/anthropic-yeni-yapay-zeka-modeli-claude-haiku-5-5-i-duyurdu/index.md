Anthropic, model ailesinin yeni üyesi Claude Haiku 5.5'i tanıttı. En hızlı küçük model olan sistem, özetleme, veri tabanı sorguları ve müşteri hizmetleri gibi işlemlerde kullanılıyor. Model ayrıca kodlama süreçlerinde alt ajanlık yapabiliyor ve bilgisayar kullanımını destekliyor.

Haiku serisinde bir ilk olan ayarlanabilir efor özelliği, kullanıcılara maliyet ile çalışma derinliği arasında seçim yapma imkânı tanıyor. Şirket açıklamasına göre model, OSWorld 2,1 testinde %72,4 ve Terminal-Bench 4,0 testinde %39,2 başarı elde etti. Yüz bin token altındaki girdilerde milyon token başına 0,10 dolar, çıktılarda ise 0,50 dolar ücret uygulanıyor.

Claude Haiku 5.5, Anthropic platformunun yanı sıra Amazon Web Services, Google Cloud ve Microsoft Azure üzerinden erişime açıldı. Öte yandan şirket, Claude Sonnet 5.5 modelinin önbellek okuma ücretini de milyon token başına 0,10 dolara çekti.
